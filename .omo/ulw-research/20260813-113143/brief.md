## 현재 확인된 기준선

- BurnGuard Design은 설치된 `claude`와 `codex` CLI를 채팅+캔버스 워크플로로 감싸는 로컬 우선 도구다. [README.md]
- 현재 저장소 버전은 `0.4.0`이고 Bun 워크스페이스의 backend/frontend/shared 패키지로 구성된다. [package.json]
- Claude Design은 designs, decks, prototypes를 대화형으로 만드는 Anthropic beta 제품이다. [Claude Design product page](https://claude.com/product/design)

## 조사 축과 소유권

1. **BurnGuard 기준선**: 현재 기능, 데이터 흐름, 테스트, 구조적 부채와 확장 지점.
2. **Claude Design 공식 경험**: 공식 페이지·도움말·발표문에서 기능, 워크플로, 제약, 변화 속도 확인.
3. **AI 캔버스·앱 빌더**: Onlook, Dyad, bolt.diy, Open Lovable 계열의 생성-미리보기-수정 루프.
4. **비주얼 편집·디자인 시스템**: Penpot, Plasmic, GrapesJS, tldraw 등의 선택·조작·토큰·컴포넌트 설계.
5. **프레젠테이션 제작**: 오픈소스 슬라이드 생성기와 deck 편집기의 구조, 내보내기, 렌더링.
6. **로컬 에이전트 런타임**: CLI 어댑터, 스트리밍, 승인, 체크포인트, 재시도, 격리, 모델 교체.
7. **보안·데이터·배포**: 로컬 파일 권한, 명령 실행 경계, 프로젝트 이식성, 백업과 진단.
8. **제품 우선순위·반대검증**: 기능 가치, 구현 비용, 결합도, 차별성, 근거 독립성 공격.

## 비교 기준

- 사용자 가치: 반복 작업 절감, 직접 조작 가능성, 결과물 품질, 학습 비용.
- BurnGuard 적합성: 로컬 우선, 기존 CLI 재사용, 오프라인/프라이버시, 현재 아키텍처와의 결합도.
- 구현성: 복잡도, 외부 의존성, 테스트 가능성, 플랫폼 이식성, 유지보수 비용.
- 차별성: Claude Design 모방이 아니라 로컬 프로젝트·에이전트·파일 시스템을 활용하는 고유 장점.
- 증거 수준: 공식 문서, SHA 고정 코드, 실행 검증, 독립 출처 수, 반증 검색 결과.
